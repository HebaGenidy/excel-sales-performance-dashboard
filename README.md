# 📊 Sales Performance Executive Dashboard

## 📌 Project Overview
This project features an interactive **Sales Performance Executive Dashboard** built using **Microsoft Excel**[cite: 1]. The objective of this dashboard is to analyze revenue distribution, regional performance, sales rep efficiency, and product categories to provide actionable insights for executive decision-making[cite: 1].

---

## 🛠️ Tools & Functions Used
* **Data Transformation & Logic:** `XLOOKUP`, `COUNTIFS`, `SUMIFS`.
* **Dynamic Interactivity:** **Slicers** (Order Status: *Cancelled, Delivered, Shipped* | Regions: *East, North, South, West*)[cite: 1].
* **Data Visualization:** Pie Chart, Horizontal Bar Chart, Column Charts with Dual Metrics[cite: 1].
* **Design & Layout:** Custom UI layout with rounded cards and a dark purple color palette[cite: 1].

---

## 🎯 Key Business Questions Addressed
1. What is the revenue distribution across different geographical regions?[cite: 1]
2. Who are the top-performing sales representatives driving revenue?[cite: 1]
3. How do monthly revenue and total order counts trend over time (Q1 & Q2)?[cite: 1]
4. Which product categories generate the highest revenue?[cite: 1]
5. How can sales performance be filtered dynamically by order status and region?[cite: 1]
